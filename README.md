# 登录流程交互原型

这是一个无需构建步骤的静态交互原型。

当前已补充两条安全登录链路：

- 已注册未开户及已实名开户用户：优先进入面容登录，面容不可用时直接进入手势密码；忘记手势密码时按能力降级到本机号码一键登录或短信登录。
- 新用户：首次登录后设置并二次确认手势密码；进入首页后再询问是否开启面容快捷登录，可选择立即开启、下次再说或15天内不再提示。

## 本地预览

直接用浏览器打开 `dist/index.html`，或通过任意静态文件服务器发布 `dist` 目录。

## 部署

将 `dist` 目录中的全部内容部署到网站根目录即可。入口文件为 `dist/index.html`。
